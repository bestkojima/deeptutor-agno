| --- | --- | --- |

## 复现入口

- 恢复确认过且中断的研究：`POST /api/tasks/{id}/resume`，请求体 `{"answers":{}}`。任务详情返回可恢复状态与 SSE 游标。不自动重启外部检索。
- 作答：`POST /api/tasks/{id}/quiz/submit`，如 `{"answers":{"q1":1}}`，键为学生任务给出的题目 ID，选项索引从 0 开始。提交已评分题的相同答案是幂等重试。
- 固定动画：创建 `video_lesson` 任务，输入 `{"animation":{"template":"quadratic_trace","a":1,"b":-4,"c":3,"domain":[-1,5],"duration_seconds":6}}`。可用离线 provider 直接生成，不调用模型。修订：`POST /api/tasks/{id}/video/revise`，同样传 `animation`。
- 恢复和修订均保留同一任务 ID。所有凭据仅服务端本地配置，未纳入代码或附件。

## 执行证据

真实模型验收开启了请求数、输出长度及总预算限制。首次发现 GPT-6 Luna 的 Chat Completions 工具兼容错误（HTTP 400），修复后的 **9 个成功请求**返回用量；按标准公布价格估算合计 **0.0006966 美元**。这是响应内用量折算，不是账单；未查证扣赠送还是购买余额。离线回归使用真实 Agno 编排、模拟模型或 HTTP 响应；未发额外生成请求。

实施规格阶段的离线验收：147 项后端测试全部通过（包含真实 XeLaTeX/Poppler 编译和 FFmpeg 编码）及 4 套前端 Node 测试通过。独立样片经 ffprobe 验证为 640×360、H.264、72 帧、6 秒，字幕终点为 6 秒。未以 Node 的模拟 DOM 验收代替浏览器、Expo 或真机实测。

Agno 3.2.0 升级后，2 项新回归覆盖 Responses 两次工具请求的消息回放和任务路由，总数为 149 项。真实 Luna 的 Chat Completions 验收与新版 Responses 的模拟 HTTP 验收是两个独立结果；后者未调用线上接口。
