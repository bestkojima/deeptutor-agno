# 个性化出卷：首版权重默认策略

这份文档描述首版默认行为，不是长期约定。出卷必须遵守的边界见[架构决策](adr/0001-backend-owned-exam-weighting.md)。

- 先按题型加权，再在选中的题型内按知识点加权。
- 默认每个命中的题型或知识点在其基础权重上加 1；同项只加一次。首版不按次数、时间或置信度进一步加权。
- 记忆只标了知识点而未标题型时，默认只影响知识点层。
- 后续可调系数、增加证据权重或替换实现。只要保持既定设计边界，这些变化仍属于策略调整。

## 当前验收范围

先用合成蓝图验收普通出卷的结构、答案键和进度事件，不以此声称还原真实参考卷风格。真实题型参考、题位知识点约束和记忆接口留待确认。在没有这些输入时，照常按给定蓝图出普通卷，不应用个性化。
