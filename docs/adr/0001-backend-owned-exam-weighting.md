# 按题型、再按知识点选择出题目标

个性化出卷按两层加权：先作用于题型，再作用于该题型下的各知识点。记忆由独立系统提供，出卷只消费其检索结果；权重计算与带 seed 的抽样由出卷后端负责，Agent 负责把后端选定的目标写成题。这样可以回放选择过程，单独验收个性化策略，不把模型生成文本的随机性混进题型或知识点选择。

出卷蓝图规定的各题型题数和分值保持不变。题型权重只决定优先个性化哪些已有题位，不增减题位。不预设固定个性化比例或题数，也不凑名额；实际有多少题位被个性化，由权重计算及带 seed 的抽样决定。

权重计算细节属于可替换的出卷策略，不是架构约束。首版默认采用[简单弱项加权](../exam-weighting-policy.md)，后续可根据验收结果调整或替换策略，无需改变两层加权顺序、记忆检索边界或出卷蓝图。

待定：基础权重、如何按权重决定保留普通出题或个性化、各题位允许的知识点从哪里来。
