# 当前实现、验收与 DeepTutor 差异

运行目标：本机单用户试用。不是已验证的 1:1 替代品。真实 Agno 2.3.21 的 Agent、Workflow、Step 已在模拟模型响应下运行，未调用真实模型 API。

| 功能 | 当前原型 | 尚未等价或尚未实测 |
|---|---|---|
| Chat | Agno Agent + 教育工具白名单，轨迹记录；可传历史上下文 | 上游工具、附件与跨任务工作区不是全部接通 |
| Ask Questions | 真模型分支生成上下文提问卡；数据库存卡、等答案、恢复原任务；Demo 用固定逻辑 | 尚无真模型联调；前端仅实现文本回答 |
| Quiz | 生成选择题，校验选项、答案索引和解析，经验证后逐题发送事件 | 不是逐题生成时实时输出；上游题型、仿题、跟进未全部实现 |
| Visualize | 有数据校验的柱状图/折线图，可生成可信 SVG 字符串；其余格式返回不可执行源码 | HTML/SVG/Mermaid/Manim 的上游可交互播放器和渲染器未接通 |
| Video Lesson | FFmpeg H.264 MP4、WebVTT 和浏览器播放控件；可选 Edge 旁白开关 | 非上游 Remotion/Node 22+/TSX；Edge 未接真实服务测试 |
| Immersive Reading | 摘录含页码/时间戳并校验引文；命令行支持提取有文本层的 PDF 或已有 VTT/SRT | 不执行扫描 PDF OCR、音视频转录，不含原文旁阅读、图片理解或批注 |
| Research | 提纲预览、确认后检索和分阶段 Agno Agent、引用验证；可配 Tavily 与 arXiv，工具失败可报告 | 不含向量索引、上游并行研究块或完整失败块统计；远程工具未联测 |
| Solve | 计划、求解、答复、复核；可用有限算术工具 | 非上游逐步门禁与有界重规划；模型复核不是形式化证明 |
| Exam | 提取文本样卷蓝图后返回待确认状态；结构严格校验、随机 seed、题干去重、试卷与答案分离 | 未拿真实样卷验证；版式为 JSON/Markdown/纯文本，不复刻 PDF 像素；文风、难度与正确性不能仅凭结构保证 |

## 本地复现

- 启动方式见 README；默认 Demo 不访问远端。
- 模型变量：OPENAI_API_KEY、AGNO_MODEL，可选 OPENAI_BASE_URL（仅服务端可信地址）。
- 视频：FFmpeg、Pillow；CJK 字体可用 TUTOR_VIDEO_FONT 指定。Edge 要安装 edge-tts 并设 TUTOR_ENABLE_EDGE_TTS=1；每个任务仍须显式选择 tts.provider=edge。旁白文本会发送微软。
- Research：服务器启用 TUTOR_ENABLE_ARXIV=1 或 TUTOR_ENABLE_WEB=1，Web 需 TAVILY_API_KEY。任务仍须显式设 use_arxiv 或 use_web；查询会发送相应服务。
- 已有 PDF/字幕：python scripts/extract_sources.py source.pdf 或 source.vtt，结果填到 inputs.sources。PDF 需要 pdftotext。
- 样卷：POST /api/exam/blueprint，传 sample_text；人工核对返回的 blueprint 后，用 examples/exam-request.json 的格式发给任务接口。提取本身使用配置的模型 API，不能上传不愿发给提供商的试卷。
- 事件：SQLite 持久化和 SSE 续传；进度按阶段显示，不是预计剩余时间。测试用数据不会打入 ZIP。

## 实测记录

- 后端 unittest：42 项通过（包含真实 Agno 编排、模型响应模拟、API/SSE、蓝图、媒体及安全边界）。
- 前端：Node 语法与模拟 DOM 行为测试通过，含提交、SSE 去重与重连、暂停恢复、失败显示。
- 视频：实际生成 2 段中文课程，FFprobe 确认 H.264 960×540、2 秒，字幕检查通过。没有执行 Edge TTS 或真浏览器播放验收。
- 未做生产、真 API、真实样卷风格/难度和浏览器端到端验收。
