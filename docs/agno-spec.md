# 规格：Agno 复现 DeepTutor 教学流程与独立 Exam

## 问题

教师和学生需要在一个简洁工作台使用 DeepTutor 式教学能力，但更换为 Agno 编排后，不能只复刻入口或生成一段文字。应能看见工具与任务进度，能验证什么时候暂停、恢复、产出结果或拒绝失败结果。整卷出题是独立能力，不等于 Quiz。

## 方案

以已发布的 Agno 行为复现版为起点，保留可验证的 Agno Agent/Workflow，优先复现上游的可观察行为。后端负责执行和验证，前端主要显示轨迹、进度，只为验收增加必要的澄清卡、题目、图形与材料视图。若确认是框架硬限制，才在规格之外的实现对照文档记录失去的行为和证据；缺依赖、沙箱或时间不等于框架限制。

## 用户故事

1. 作为学生，我能在 Chat 使用已授权工具，看到成功或失败而不是假结果。
2. 作为学生，我能回答 Ask Questions 澄清卡，并让同一个任务继续处理原问题。
3. 作为学生，我提交两次也不会因此执行两轮。
4. 作为学生，我能逐题收到 Quiz 题目；后续题失败时，已经收到的题仍可做。
5. 作为学生，我能在作答后看到客观题反馈，不会在作答前看到答案。
6. 作为学生，我能拖动函数参数，看到后端确定性计算的新图，不需要重跑模型。
7. 作为学生，我能打开数学微课，看到和时间轴一致的字幕；后续渲染失败不覆盖已通过产物。
8. 作为学生，我能点阅读引用，跳到原文页或视频时间，只有精确匹配的文本才高亮。
9. 作为学生，我能确认研究提纲，看见子题进度；运行中断后可继续尚未完成的子题。
10. 作为学生，我能区分研究的部分失败和无有效证据，不会收到伪造的报告。
11. 作为学生，我能让 Solve 按计划推进、校验和有限重试；没做完不会标为成功。
12. 作为老师，我能以同一个合成蓝图换题，保留题号、题型、题数、顺序、分值和总分。
13. 作为老师，我能预览符合 2026 高考数学新课标Ⅰ卷体例的合成样张：19 题、150 分、120 分钟；单选 8、多选 3、填空 3、解答 5。
14. 作为老师，我能得到学生版和独立答案版的 PDF 与 Markdown，以及可复用的 LaTeX 样式源码。
15. 作为老师，我能离线查看 Markdown 里的图，图和 PDF 都来自同一个 TikZ 图源，不会各画一套。
16. 作为开发者，我能从固定版本代码对照找到上游和 Agno 的入口、校验和输出边界。
17. 作为开发者，我能区分离线模拟、真实模型验收和第三方服务限制。

## 实现决策

- Agno 编排与工具是主体；确定性业务校验、任务状态、事件持久化、渲染及媒体是应用职责。现有 FastAPI、SQLite、SSE 保持；不换成上游传输实现。
- 只注册受控工具和可验证的渲染参数；不执行模型生成的 HTML、TSX、Python 或任意 LaTeX。视频待办只用固定、受控的动画模板。
- 同一参考卷蓝图生成可变题目，不允许静默猜测缺失分值/题型。样式与内容分离；LaTeX、PDF、Markdown 共享同一份校验通过的卷面数据；SVG 随 Markdown 一起打包并以相对路径引用。
- 已有静态样式和 PDF/答案样张不是自动导出；交付链路见 #7。现有 Markdown 文本渲染也不等于有配套 SVG 的完整交付包。
- 已定的未来边界：记忆只经记忆系统接口读取，先按题型再按知识点加权，不改卷面结构；计算策略可替换。正式接口、题位知识点和启用规则不在这一版落地。

## 测试决策

1. **任务 API + SSE**：以提交、暂停、恢复、事件回放、终态和产出为黑盒入口。验证进度、工具失败、重复提交、部分失败和中断恢复。内部步骤顺序只在影响外部合约时断言。优先复用现有 API 与事件测试，不为验收另建一套测试 API。
2. **同一 Exam 交付包**：以学生视图和归档为黑盒，对 PDF、Markdown 与答案数据核对题号/题型/分值，验证学生版不含答案、SVG 相对引用可离线解析，并检查图形与 PDF 一致。
3. 使用真实 Agno 编排、模拟模型的回归覆盖确定性行为；真实模型试跑单独验收（#1），不可用模拟替代结果。不以模型复核宣称数学正确证明，不以合成题宣称与正式试卷难度一致。

## 不在范围

任意生成代码执行；完整 Expo 改造；全量上游插件；未授权外部检索；原始音视频 ASR、扫描件 OCR、持久阅读批注、记忆/个性化出题。真实参考卷的命题风格和难度等价需单独验收。

## 关联

实施基线：[当前已发布源码](https://github.com/bestkojima/deeptutor-agno/commit/c6fc527d70504547a889ee8f4569effc4b320e34)，上游 DeepTutor v1.7.2。独立工作单：#1 真实模型验收，#2 Quiz，#3 数学图，#4 阅读定位，#5 研究恢复，#6 固定模板微课，#7 Exam 导出。此规格不重复创建这些工单，也不改变它们的状态。
